# OpenSpec

Specs and change proposals for this repo.

- `changes/<change-id>/`: proposed changes (proposal.md, design.md, tasks.md, specs/). A change counts as approved once Duane approves it and it is merged here.
- `specs/`: current accepted specs, filled in as changes are archived.

The end-to-end workflow (explore, interview, propose, apply, archive) is in [`docs/openspec-workflow.md`](../docs/openspec-workflow.md). Merging an approved change folder to `master` is the green light for apply; a workflow then starts Claude so you do not have to write an `@claude` comment.

The local builder only works from approved changes on `master`.
